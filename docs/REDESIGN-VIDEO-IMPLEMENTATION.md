# DesktopCollage redesign based on WinDock reference

## This commit
- Replaces the initial DEVELOPMENT prototype visual with an obsidian and blue-green glass-style collection.
- Applies rounded corners, mint accent labels, subtle borders and revised button styles.
- Adds an explicit resize grip to independent collection windows.
- Keeps non-destructive file references and existing collection persistence.
- Does not replace the real Windows icon shell, inject into Explorer, or implement Android controls.
